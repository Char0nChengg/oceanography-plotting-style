# 设计立场：克制、清晰、以图传意

> 本文说明本项目的审美与技术偏好。它不是期刊官方规范，也不要求其他作者采用；投稿时仍以目标期刊的最新 author guidelines 为准。

## 为什么会有这份立场

本项目来自作者在物理海洋学论文绘图、投稿与返修中的长期实践。不同作者、期刊和审稿人有各自的视觉传统，这些传统没有唯一正确的答案。不过，有些常见的投稿图把较多注意力放在装饰、饱和度或层层堆叠的文字上，反而削弱了数据本身的可读性。本项目选择明确站在“少一些装饰、多一些信息”的一边，而不跟随这类表达。

这是一种个人偏好，不是对其他作者或期刊的评判。它的价值在于**可重复、可检查、可交付**，而不是声称自己代表唯一正确的审美。

## 四条基本原则

### 1. 只用 cmocean，不用彩虹色标

所有连续色标优先从 [cmocean](https://matplotlib.org/cmocean/) 中选择，不使用 jet、rainbow 等彩虹色标。彩虹色标会在没有物理边界的数据上制造虚假的“分界”和顺序感；cmocean 的感知均匀色标更适合表达海洋与大气的连续场。

色标由变量属性决定，而不是由个人喜好临时决定：

- 有界正值、振幅、RMSE：`cmo.dense`、`cmo.speed`；
- 正负距平、差值：`cmo.balance`，并使用对称的 `vmin/vmax`；
- 温度、盐度：`cmo.thermal`、`cmo.haline`；
- 地形、深度：`cmo.deep`；
- 相位：`cmo.phase`；
- 速度：`cmo.speed`。

具体范围和 `extend` 必须由数据是否被截断决定，不能只凭变量正负猜测。

### 2. 图优先，文字克制

图应该主要靠图像本身传递信息，而不是靠大段文字、主标题和重复标签：

- 不设整张图的 main title；用每个子图的 subtitle 和 `(a)`、`(b)` 面板字母建立层级；
- 能共享的横纵坐标就共享；内侧面板隐藏重复刻度标签，只在最左列/最底行保留；
- 轴标签只在必要时出现，且必须带单位；
- 图例、注释和箭头只保留解释数据所必需的部分，不把方法段落搬进图里。

“少文字”不是“少信息”。好的图应该让读者先看到结构、梯度、异常和差异，再去看标签。

### 3. Colorbar 清晰，但不占用主图空间

Colorbar 是读图工具，不是主图的一部分。优先把它放在外置的独立列、图下方或图内 inset 中，避免压缩地图和剖面；多面板同变量共用一条 colorbar。

在不影响可读性的前提下，可以使用分段、截取或线性拼接的自定义 colorbar，但必须满足：

- 标签含变量名和单位；
- 刻度 4–7 个；
- `extend` 与数据是否越界一致；
- 不为了“好看”把无物理意义的中心硬塞进色标。

### 4. 分析图也使用同一套视觉语言

CCA、小波、谱分析、EMD 等分析图不是另一套审美。它们同样遵循“图优先、色标诚实、共享坐标、少文字”的原则；具体图型见 [figure-recipes](../references/figure-recipes.md)。

这些做法已在作者本人的投稿与返修中使用过，并接受过期刊编辑和审稿人的检验。但“经过期刊检验”不等于“适用于所有期刊”，也不替代同行评审和统计假设检查。后续计划整理一套**由问题驱动的海洋/大气统计分析教程**，把“为什么这样分析、如何检查假设、如何画图”放在同一个流程里，而不是只给绘图代码。

## 边界

- 期刊的 figure preparation 要求优先于本项目；栏宽、字号、字体和格式必须按最新指南核对。
- 本项目的期刊预设、CVD 筛查和布局检查都是经验工具，不是官方认证。
- 合成数据模板必须保留 `--demo` 和清楚的合成标识，不能伪装成真实结果。
- 审美可以争论，但数据、单位、色标范围和统计假设必须可验证。
